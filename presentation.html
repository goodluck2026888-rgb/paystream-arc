The Problem

Traditional recurring payments are broken for machine-to-machine economies:

⏳ Settlement lag

Invoices, net-30 terms, and batch ACH create cash-flow gaps for vendors.

🔒 Locked capital

Subscriptions require upfront payment or escrow before service is consumed.

🤖 Agent friction

AI agents cannot sign paper contracts or manage credit-card retry logic.

📊 No visibility

Businesses lack real-time insight into which streams are healthy or interrupted.

Our Solution

PayStream Arc turns recurring USDC transfers into on-chain streaming payment agreements.

Per-secondflow accrual
$0.001per API request
Anytimewithdrawal by receiver
  • Sender starts a stream with a fixed flowRate in USDC/second.
  • Receiver withdraws accrued balance whenever they want.
  • Either party can stop the stream at any time.
  • AI agents query analytics through an x402 paywall.

On-Chain Protocol

PayStream.sol stores streaming agreements on Arc L1.

struct Stream { bytes32 streamId; address sender; address receiver; uint256 flowRate; // USDC per second uint256 startTime; uint256 stopTime; uint256 withdrawnAmount; bool active; } function startStream(address _receiver, uint256 _flowRate) external; function stopStream(bytes32 _streamId) external; function withdrawFromStream(bytes32 _streamId) external;

All math is done in base units (6 decimals) and settlement pulls USDC from the sender at withdrawal time.

Stream Detection Engine

The indexer groups USDC transfers by sender → receiver and scores them for recurrence.

Interval regularity

Coefficient of variation between consecutive transfer block numbers.

Amount consistency

CV of transfer values to detect subscription-like fixed payments.

Flow rate

Total value divided by stream duration in seconds.

Interruption alert

Flags streams that have not received a payment within 50 blocks.

x402-Powered API

Agents pay $0.001 USDC per request to access real-time stream data.

GET /health # free GET /stats # free GET /streams # x402: $0.001 USDC GET /streams/:id # x402: $0.001 USDC POST /api/stream/settle # x402 + Circle AppKit send()

Unpaid requests return 402 Payment Required with a WWW-Authenticate header; paid requests include an X-Payment-Response settlement proof.
